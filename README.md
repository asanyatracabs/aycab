# AYCAB

AYCAB is a cab and outstation travel booking platform.

## Project modules

1. Passenger and Driver mobile application
2. Driver registration and verification
3. Ride booking and fare negotiation
4. Driver subscriptions (Free and Paid)
5. Admin web portal
6. Payments and notifications

## Technology

- Mobile App: React Native
- Admin Portal: React
- Backend: PHP Laravel
- Database: MySQL

## Languages
- English
- Hindi

## Launch
Pilot launch in selected cities in India.
